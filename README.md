# Python Learning Journey 🐍

> A documented, hands-on journey through Python — from the fundamentals to more advanced programming concepts.

## About

This repository contains my personal study notes, code examples and practical exercises as I learn Python from the beginning.

Each lesson is documented in a separate Python file (`lesson1.py`, `lesson2.py`, etc.), providing a chronological record of the concepts I've studied and practised.

**The purpose is simple:** document what I learn, put theory into practice, and build a solid understanding of Python over time.

This is an ongoing learning project, not a claim of expertise. The code represents my progress, and there is always more to learn.

_Lesson descriptions will be updated as the repository grows._

## Getting Started

You are welcome to explore the lessons and follow the same learning path.

### Requirements

- Python 3.x
- A code editor (VS Code recommended)

### Run a Lesson

Clone the repository:

```bash
git clone https://github.com/Jabutec/python_lessons.git
```

Navigate into the project:

```bash
cd python_lessons
```

Run any lesson:

```bash
python lesson1.py
```

Replace `lesson1.py` with whichever lesson you want to explore.

## Learning Approach

- Learn a concept.
- Practise it through code.
- Experiment with different approaches.
- Build on previously learned concepts.
- Keep documenting progress.

## Follow Along

If you're also learning Python, feel free to clone the repository, explore the examples and work through the lessons yourself.

You don't need to be an expert to start learning, and you don't need to have everything figured out along the way.
